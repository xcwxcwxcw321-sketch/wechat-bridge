# wechat-bridge

微信 iLink / ClawBot 官方通道的桥接程序：登录后长连接收消息、落盘，配合 Muse 做自动回复。

## 文件

- `bridge.py` — 桥本体（仅用 Python 标准库），子命令：
  - `login` 生成登录二维码，`wait-login` 等待扫码确认
  - `serve` 长连接收信：新消息先秒回“收到，我想想…”，正文随后补上
  - `send` 用最近一条消息的上下文手动发一条
  - `status` 查看登录与收发状态
- `hooks/wechat-inbox-watch.sh` — 收件箱看守脚本：发现未处理的新消息时唤醒自动回复

## 说明

- 登录凭据保存在本地 `state/session.json`（权限 0600），**不包含在本仓库中**，任何时候都不应上传、分享或写入聊天记录。
- 官方通道的限制：仅支持 1 对 1 私聊，不支持群聊；机器人不能主动发起会话，需要对方先发消息；连续发送过多条而对方不回复会被限制，回复一条即重置。
